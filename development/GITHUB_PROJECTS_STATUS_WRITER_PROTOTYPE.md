# Projects status writer: review prototype

This branch contains a **disabled prototype** for one controlled test of existing issue #4 on `hva73/1`. `LIVE_WRITE_ENABLED = False` is hard-coded. The draft branch contains a workflow for manual dispatch and future separate write comments, whose write job has a second hard stop, `false`, and shares the dry-run concurrency group. Write comments use `ESCAPE_PROJECTS_WRITE_V1`; dry-runs use `ESCAPE_PROJECTS_DRYRUN_V1`, so the dry-run does not consume the write request. The workflow exists only in this draft branch and has not been activated. Do not remove either stop based solely on this document.

The prototype accepts only Backlog ↔ In progress and requires the caller to provide the existing authenticated, unedited-comment validation, a protected one-time journal claim, and serialization of all cooperating requests. It verifies owner, project, active item, issue identity, unique Status field and desired option, checks expected status, obtains a confirmed claim, and revalidates comment and board before attempting a single parameterized GraphQL mutation. It performs readback, treats an unknown mutation/readback outcome as uncertain, and never retries automatically. Forty-five tests across the prototype, integrated runner, audit and existing checks passed both locally and in GitHub Actions run 42878121321 without a Projects credential. The live synthetic audit tests verified all three explicitly labelled outcomes and duplicate suppression (run 42876842422), and workflow failure reporting and duplicate suppression (run 42877964977), on Issue #4 without a Projects credential. A disabled runner connects the existing validator, journal claim and Issue audit in isolated tests. All mutation responses in these tests were simulated. Read-only Actions run 42875515450 additionally verified the prototype's actual GraphQL query and Issue #4 Status field against the existing project. No live Projects write was made.
